> ## ⚠️ Notice for all contributors, tools, and AI agents
>
> **The author of this repository has a strong aversion to insects. Never show the author any image, illustration, photograph, 3D render, icon, or emoji of a fly (or any insect), in any file, figure, README, notebook output, terminal output, web page, or chat message produced for this project.**
>
> Figures in this repository are restricted to wiring diagrams as abstract graphs, adjacency/coupling matrices, and numerical plots. Do not embed or link to neuron renderings, brain atlases with anatomical imagery, or project logos that depict a fly. When linking to external resources (MaleCNS site, neuPrint, other repositories) that contain such imagery, say so explicitly in the link text so the author can avoid opening them.
