## Definitions and fixed thresholds

- Node set: `status == 'Traced'` and (`class` in {ALPN, Kenyon_Cell, MBON, DAN} or `type` in {APL, DPM}).
- Roles: PN = ALPN, KC = Kenyon_Cell, MBON, DAN, APL, DPM. Side = `somaSide` (L/R/M/NaN).
- Edge weight = synapse count of the directed pre -> post connection (min confidence 0.5, traced-only file).
- Thresholds reported: weight >= 1 (all), >= 5 (common 'significant' cutoff), >= 10.
- Sign: `consensus_nt`, falling back to `celltype_predicted_nt` when consensus is unclear. acetylcholine -> +1, gaba -> -1, glutamate -> -1 (fly glutamate mostly inhibitory), other/unclear -> 0 (unknown).
- 'Per side' tables use edges whose pre and post somas are on the same side.
